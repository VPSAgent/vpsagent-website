Every app lives behind its own locked door.

Built for affordable 1 to 2 GB Ubuntu servers without sacrificing defense-in-depth between projects.

Hardened app containers

Each workload drops all Linux root capabilities, blocks privilege escalation, binds its own Docker bridge network, and enforces CPU and memory limits so one noisy app never starves your server.

cap_drop: ALL · no-new-privileges · 0.5 vCPU / 512m default

Private Postgres & Redis companions

Spin up per-app postgres:16-alpine and redis:7-alpine databases inside that app's private bridge network. Databases stay unreachable from the public internet and sibling apps.

Postgres 16 Alpine · Redis 7 Alpine · Private bridge only

Encrypted secrets & scrubbed logs

Environment variables stay encrypted at rest inside built-in node:sqlite (WAL mode) and are automatically redacted from container logs, audit trails, and every MCP response returned to your AI.

SQLite WAL state · Auto secret redaction · Full audit trail

Automatic Caddy 2 HTTPS & Git builds

Point any domain and Caddy 2 issues Let's Encrypt TLS certificates automatically. Deploy from Docker Hub, GHCR, or build directly from private GitHub repositories via Dockerfile.

Caddy 2 Auto-TLS · Private GitHub tokens · SSH tunnel setup
