Get it in your inbox

Three steps. Then you just talk to your agent.

  1. 01

    Install on your server.

    One command on a fresh Ubuntu 22.04 or 24.04 VPS. Docker, the control panel and HTTPS routing are set up for you.

  2. 02

    Connect your agent.

    Create a pass in the dashboard and paste the MCP link into Claude Code, Codex, Cursor or any MCP client.

  3. 03

    Ask it to ship.

    "Deploy github.com/me/app to app.mydomain.com with Postgres." Your agent builds, deploys, wires the domain, checks the logs and tells you when it's live.

Use the agent you already have.

VPSAgent has no chat window and no LLM bill of its own. It gives your coding agent 30 tools for your server over one MCP link. Pick your client and copy the snippet.

claude mcp add (terminal) 
claude mcp add --transport http vpsagent https://vps.yourdomain.com/mcp \
  --header "Authorization: Bearer vpsmcp_your_scoped_key"
Transport protocol
Streamable HTTP (POST /mcp)
Available tools
30 tools: deploy, logs, domains, env, files, services, server commands.
Permission levels
5 pass levels, from Look Only to Full Server Admin.
App lock
Optional: limit a pass to one app.

What your agent can do.

30 MCP tools to deploy apps, wire HTTPS domains, spin up databases, debug logs and manage the server itself.

Ship

Deploy from GitHub (public or private), Docker Hub or GHCR. Rebuild on demand.

deploy_app · rebuild_app · inspect_git_repo

Domains & HTTPS

Point a domain and certificates are issued and renewed automatically.

set_app_domain

Databases

Give any app its own Postgres 16 or Redis 7, reachable only from that app.

postgres:16 · redis:7

Run & debug

Start, stop, restart, read logs, or run a command inside the app.

get_app_logs · restart_app · exec_in_app

Config

Set environment variables. Secret values are stored encrypted and never echoed back to the agent.

update_app_env

The server itself

Health, files, services and shell commands on the host, each waiting for your OK unless you choose otherwise.

get_host_health · read_file · manage_service · run_host_command

Your agent asks before the big moves.

Each pass has a level. Let your agent deploy on its own and ask before deleting, or have it queue every change for one click. Everything it does lands in a history you can scroll back through.

One command to install.

Runs on a fresh $5 Ubuntu 22.04 or 24.04 LTS VPS. No cloud account, no external database.

$ curl -fsSL https://raw.githubusercontent.com/VPSAgent/vpsagent/main/bootstrap/install.sh | sudo bash
