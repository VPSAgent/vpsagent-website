Zero-Root Safety Wall

AI proposes the change. You sign off before it ships.

Core containers never mount /var/run/docker.sock. Every Docker and Caddy command passes through an allowlisted Python Runtime Bridge on a private host Unix socket—and risky actions pause for your click.

  • No raw Docker socket: AI agents cannot escape containers or read sibling volumes.
  • Interactive approval queue: Inspect target app, ports, memory limits, and image source before running.
  • Scoped autonomy: Let trusted agents auto-deploy safe updates while still gating deletions.

Locked Apartment Architecture

Every app lives behind its own locked door.

Built for affordable 1–2 GB Ubuntu servers without sacrificing defense-in-depth between projects.

Hardened app containers

Each workload drops all Linux root capabilities, blocks privilege escalation, binds its own Docker bridge network, and honors strict CPU and memory limits so one noisy app never starves your box.

cap_drop: ALL no-new-privileges 0.5 vCPU · 512m default

Private Postgres & Redis companions

Spin up per-app postgres:16-alpine and redis:7-alpine databases inside that app’s private network—never exposed to the public internet or other apps on the VPS.

Postgres 16 Alpine Redis 7 Alpine Private bridge only

Encrypted secrets & scrubbed logs

Environment variables are encrypted at rest inside built-in node:sqlite (WAL mode) and automatically redacted from container logs, audit trails, and every MCP response returned to your AI.

SQLite WAL state Auto secret redaction Full audit log

Automatic Caddy 2 HTTPS & Git builds

Point any domain and Caddy 2 issues Let’s Encrypt TLS certificates automatically. Deploy from Docker Hub, GHCR, or build directly from private GitHub repositories via Dockerfile.
